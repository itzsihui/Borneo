# Sample inventories

Drop any CSV on **Open a store** (`/onboard`). Columns: `title`, `description`, `quantity`, `price` (XSGD). Prices are tiny so Fuji test buys stay cheap.

| File | Store vibe |
|---|---|
| `hackathon-inventory.csv` | StraitsX / AgentiX merch |
| `phone-store.csv` | Phones + accessories |
| `clothing-boutique.csv` | Apparel |
| `coffee-roaster.csv` | Bags + cold brew |
| `bookstore.csv` | Books + stationery extras |
| `sneaker-drop.csv` | Footwear drop |
| `snack-kiosk.csv` | Pantry snacks |
| `flower-shop.csv` | Blooms + gifts |
| `stationery.csv` | Desk supplies |
| `skincare.csv` | Beauty shelf |
| `camera-gear.csv` | Photo accessories |

Example chat instead of CSV: `phone store: 5 iphones, 5 samsungs` then set prices in the form.
